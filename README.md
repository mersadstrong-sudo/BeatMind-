# BeatMind 🎵

AI-powered Telegram music assistant.

## Features

- 🤖 AI Lyrics Generator
- 🎹 Beat Store
- 🎁 Free Beat
- 🎤 Free Lyrics
- 🎧 Match My Lyrics
- 📂 My Works
- 💎 Wallet
- 👤 User Profile
- 🛠 Admin Statistics

## Deployment

BeatMind is designed to run on Railway.

Required environment variables:

- BOT_TOKEN
- ADMIN_IDS
- OPENAI_API_KEY
- OPENAI_MODEL
